# 电商订单录入自动化（第一版）

这是一个安全优先的半自动版本：从聚水潭当前选中订单读取文本，解析订单信息，匹配已确认物料，并填写报价单主表。默认不会点击最终保存。

## 安装

```powershell
cd "C:\Users\95403\Documents\Codex\2026-09-28\record\outputs\order-automation"
npm install
```

## 运行

```powershell
npm start
```

程序会打开一个独立的 Edge 配置目录。首次运行请手动登录聚水潭和内部报价单系统，并分别打开两个页面。之后在聚水潭选中一笔订单，回到终端按 Enter。

## 当前安全限制

- `config.json` 默认 `dryRun: true`，不会自动保存。
- `material-map.json` 中的初始物料都是 `pending_confirmation`，未确认物料不会自动填表。
- 复杂窗型、尺寸不完整或物料不唯一时自动暂停。
- 成交金额保留全部小数。
- 不计算或处理明细单价。

## 下一步校准

首次在真实页面运行后，需要根据页面 DOM 校准：

1. 聚水潭选中订单行的选择器。
2. 报价单联系人、单位名称和成交金额字段。
3. 添加物料弹窗、物料搜索和候选选择。
4. 宽、高、件数、数量和备注字段。
5. 店铺名称到单位名称的映射。

完成校准后，再逐步确认物料映射并扩展自动填写明细。

## 连续抄单（开发分支）

1. 在聚水潭当前查询池中勾选两笔或更多订单。
2. 程序按页面序号执行全量预检，并显示批量确认卡片。
3. 只有全部订单预检通过时才能开始。
4. 开始后程序会取消页面多选；正式执行时始终只勾选当前一单。
5. 当前单的 ERP 链、报价链及审计记录全部成功后，自动进入下一单。
6. 任意异常都会暂停整批，不会自动跳过。

原有单笔勾选确认和终端 `run [单号]` 操作保持不变。

## 执行审计

软件自动抄单和人工接管都会写入本机 SQLite：

```text
data/audit/order-automation.db
```

审计数据包含批次、队列顺序、订单快照、权威目录、报价明细、每一步结果、耗时、凭证号和错误信息。该目录已被 Git 忽略，不会上传订单数据。

查询最近20个批次：

```bash
npm run audit
```

按订单号或批次号复盘：

```bash
npm run audit -- 2653900
npm run audit -- B20261109-120000-001
```
