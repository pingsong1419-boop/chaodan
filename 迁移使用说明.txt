订单抄单自动化——另一台电脑使用说明
====================================

一、运行条件
1. Windows 10 或 Windows 11（64位）。
2. 已安装 Microsoft Edge。
3. 目标电脑能访问聚水潭和内部报价系统。

二、首次使用
1. 把整个压缩包解压到普通文件夹，不能直接在压缩包里运行。
2. 双击“订单抄单自动化.exe”，打开图形操作界面。
3. 点击界面中的“启动程序”，程序会打开独立的 Edge 窗口。
4. 在新电脑上分别登录聚水潭和报价系统。
5. 登录状态保存在本机新建的 browser-profile 文件夹中，以后不必重复登录。

三、正常使用
1. 进入聚水潭订单查询池，选择天猫或京东。
2. 勾选订单，核对确认卡片中的订单号、金额、物料、尺寸、件数及备注。
3. 只有显示“参数完整，可以抄单”的订单才允许确认。
4. 原则：宁愿不抄，不能错抄。

四、安全规则
- 权威目录必须唯一命中。
- 已抄、发货中、等待合并、暂不抄、等通知制作和电动产品会被拦截。
- 信息缺失、目录多候选或无法可靠理解时不会执行。
- 首次在新电脑使用时，建议先选一单执行只读预览并人工核对。

五、迁移说明
- 压缩包不包含原电脑的账号登录缓存、运行日志或历史断点。
- 内置 Node 运行环境和程序依赖，无需安装 Node.js、无需运行 npm install。
- 不要单独移动 EXE；必须保留整个解压目录。
- “便携版启动.cmd”仅作为故障排查备用，日常使用不需要点击。
